# 人馬一体ジョッキー

一人称視点の障害競馬ゲーム。`index.html` 1ファイルで動きます（Three.js と PeerJS は CDN から読み込み）。

## 遊び方

出馬表で馬を選び、画面下の「出走する ▶」（または Enter キー）でスタート。

| キー | 操作 |
| --- | --- |
| ↑ / ↓ | 促す／抑える（ゲートが開いた瞬間の ↑ で好スタート） |
| ← / → | 外へ／内へ |
| **Space** | **ジャンプ**（ゲートでは好スタートにも使える） |
| Z | ムチ |
| X | なだめる |
| F | 仕掛けるフリ |

障害が近づくと画面上部にゲージが出ます。印が緑の範囲に入ったら Space。真ん中の明るい所で跳ぶと「完璧な飛越」で勢いがつき、跳ばない・早すぎると障害を引っかけて大きく減速します。障害は約220mごとに置かれます（1200mで4個、3200mで13個）。

| モード | 内容 |
| --- | --- |
| ひとりでレース | コース・相手のレベル・天候・馬場を選んで1戦 |
| キャリア | 1頭を選び、3歳の3月〜12月の10か月を戦う。毎月「レース」か「調教・休養」を選び、勝てば昇級。G1制覇と「年度代表馬」を目指す |
| ふたりで対戦 | 離れた場所の友だちとインターネット経由で同じレースを走る（同じWi-Fiでなくてよい） |

コースは芝・ダート、右回り・左回りの7つ。天候は晴れ・曇り・雨・ナイター。

## ふたりで対戦のはじめ方

1. 2人とも同じ `index.html` を開き、「ふたりで対戦」を選ぶ
2. 片方が「部屋を作る」→ 4文字の部屋コードが出る
3. もう片方がそのコードを入れて「参加する」
4. それぞれ別の馬を選ぶ。コースと条件はホスト（部屋を作った人）が決めて「2人で発走」

- 接続の仲介には PeerJS の公開サーバー（0.peerjs.com）を使います。つながった後は2人のブラウザ間で直接通信します
- 会社や学校のネットワークによっては、ファイアウォールでつながらないことがあります
- レースの計算はホスト側で行います。ホストがレース中にタブを閉じると、ゲストはメニューに戻ります
- レース中は `1` `2` `3` キーで相手にひとこと送れます

## 開発用

- `node tools/sim-test.js [コースID]` … レース計算だけをブラウザなしで回し、馬ごとの平均着順を出す（バランス調整用）
- `tools/duo.html` … 1つの画面に2人分のゲームを並べて、ふたりで対戦を試す（ローカルサーバー経由で開く）
- `index.html?debug` … `window.__jinba` に内部状態を出す（動作確認用）
